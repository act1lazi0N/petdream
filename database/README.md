# Database PetDream

Thư mục dành cho schema, stored procedure và seed của giai đoạn chức năng.
Khung hiện tại chưa có SQL thực thi và không tạo hoặc sửa database.

- Instance dự kiến: `(localdb)\MSSQLLocalDB`.
- Database dự kiến: `PetDream`.
- Thực thể dự kiến: loài, thú cưng, ảnh thú cưng, tài khoản, đơn hàng, chi tiết đơn hàng, đánh giá.
- Mỗi thú cưng là một cá thể, không dùng tồn kho theo số lượng.
- Mật khẩu và file database không đưa vào Git.
